## 무료 요금제·CPU 확인

Cloudflare 대시보드 Workers 요금제에서 **무료 / US$0 / 현재 요금제**를 확인했습니다. 업그레이드·유료 구독을 실행하지 않았습니다.
최종 배포 실시간 실행 로그 31건을 별도 수집했습니다. 요청 헤더·본문·토큰·콘솔 로그 내용은 저장하지 않았습니다.

| 작업 | 로그 표본 | CPU 중앙값(ms) | CPU p95(ms) | CPU 최대(ms) | 실행 상태 |
| --- | ---: | ---: | ---: | ---: | --- |
| 조회 | 9 | 1 | 4 | 4 | ok |
| 교과군 저장 | 16 | 4 | 5 | 5 | ok |
| 전역 설정·일괄 반영 | 2 | 3 | 17 | 17 | ok |
| 전체 | 31 | 3 | 5 | 17 | ok |

**대량 신규 반영에서 17ms CPU가 관측됐습니다.** 일반 조회·교과군 저장 표본은 10ms 이내였지만 모든 자료·모든 요청이 10ms 이내라고 보장할 수는 없습니다. 최적화 전 일괄 반영에서는 25ms도 관측돼 신규 교과군의 중복 검증을 제거했습니다. 이 값들은 서로 다른 요청 표본이므로 정밀한 전후 성능 비교로 해석하지 않습니다.
관측한 최종 실행 로그는 모두 ok였고 exceededResources·예외는 없었습니다. 무료 런타임의 일시적 CPU 여유 동작으로 성공한 요청이 포함될 수 있으므로 큰 자료의 반복 일괄 반영은 추가 분할·검증 후 사용해야 합니다.
GraphQL·대시보드 집계는 확인 시점에 데이터가 없어 0회 사용 또는 오류 0건으로 해석하지 않았습니다. CPU 결과는 실제 실시간 로그 표본이며 전체 계정·장기 부하에 대한 보증이 아닙니다.

일반 작업 측정 기준 하루 조회 1,000회와 저장 500회는 약 23,000행 읽기·2,000행 쓰기입니다. 무료 D1 기준 5,000,000행 읽기·100,000행 쓰기/일보다 적지만 초기 적재·색인 갱신·다른 앱 사용량은 별도입니다.
확인 당시 시험 D1 파일 크기는 417792바이트, 미리보기 D1은 110592바이트였습니다.
